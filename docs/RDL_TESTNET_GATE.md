# RDL Reality Mode Testnet Gate

Run the local quality gate:

```bash
bash scripts/reality-gate.sh
```

Then execute the multi-node scenario matrix in [RDL_MULTI_NODE_REALITY_HARNESS.md](RDL_MULTI_NODE_REALITY_HARNESS.md).

**Important:** passing compilation is not equivalent to production readiness. The testnet gate requires reproducible multi-node consensus and adversarial results.
